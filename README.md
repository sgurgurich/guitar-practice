# Woodshed

A guitar practice kit in the browser: metronome, circle of fifths, chord library, scales & modes, and a tuner. Every sound is synthesized with the Web Audio API; there are no audio samples.

## Run

```bash
npm install
npm run dev      # http://localhost:5173
npm test         # theory + pitch-detection tests
npm run build    # static site in dist/
```

## Tools

- **Metronome**: 20–300 BPM, tap tempo, time signatures, subdivisions, and per-beat accent/mute (click a beat on the dial). The speed trainer raises the tempo every N bars. Scheduling runs on a Web Worker, so timing holds up in background tabs. The metronome keeps running while you use the other tools; a mini player shows in the sidebar.
  Shortcuts: `Space` start/stop, `←/→` ±1, `↑/↓` ±5, `T` tap.
- **Circle of Fifths**: click a key and the wheel rotates it to the top and highlights the diatonic chords, with roman numerals. You can audition 19 common progressions in major and minor, including J-pop staples like the Royal Road and Just the Two of Us (hover any chord for its diagram), or build your own (it transposes when you change keys).
- **Chords**: 27 chord types on all 12 roots, in root position or any inversion (slash chords like C/E). Voicings are generated by searching the fretboard for playable shapes, then fingered, ranked, and drawn as diagrams. A neck map shows every chord tone.
- **Scales & Modes**: 19 scales, including all major modes, pentatonics, blues, harmonic/melodic minor modes, and symmetric scales. You get position windows, playback that lights up each note as it plays, characteristic-note highlighting, a bright→dark mode ladder, and the chords each scale harmonizes to.
- **Riffs & Tabs**: 57 original riffs, licks and exercises from beginner to expert, across rock, metal, punk, blues, funk, country, bluegrass, jazz, neo-soul, reggae, surf, indie, folk, classical and shred. Includes Drop D and Open G riffs. Sort by difficulty, filter by level, genre or technique, and play along with a moving cursor, adjustable tempo, loop and click. You can also add your own tabs.
- **Tuner**: YIN pitch detection from the microphone, with a choice of tunings, A4 calibration, and reference tones.
- **Practice Log**: a session timer, daily goal, streaks, a 14-day chart and an activity heatmap. "Log this" buttons on the metronome and riffs prefill the form. Data stays in your browser; export/import a JSON backup to move it.

**Guitar tone**: a Clean / Rock / Metal switch (in the sidebar and on each page that plays sound) runs every chord, scale, progression and riff through an amp simulator: drive, a waveshaper, EQ and a cabinet roll-off. The three tones are level-matched.

## Layout

```
src/theory/    note spelling, scales, chords, voicing search, keys & progressions (pure, tested)
src/audio/     AudioContext, Karplus–Strong guitar synth, metronome scheduler, pitch detection
src/features/  one folder per tool
src/components shared UI: fretboard, chord diagram, controls
```
